# FNHyperMount - 飞牛高可靠存储挂载管理中心

专为 **飞牛 OS (fnOS)** 打造的轻量级原生存储挂载管理中心。解决在 NAS 跨机存储挂载中常见的 **“开机掉盘卡顿”、“目标机器重启导致飞牛假死”、“只读故障无察觉” 以及 “无法区分各挂载点吞吐流量”** 的痛点。

---

## 🌟 核心杀手级特性

1. **工业级高可靠挂载机制（内置预设）**：
   - 采用 `x-systemd.automount` 访问触发机制，开机绝不阻塞系统启动；
   - 采用 `hard,intr` 稳健模式，当目标机器冷重启时，客户端自动挂起排队等待，宽限期（Grace Period）过后自动透明自愈恢复，绝不丢数据。
   - 自动联动飞牛 `/vol1` 存储池就绪时机，解决系统开机初始化时序冲突。
2. **向导式一键添加（NFS Mount Wizard）**：
   - 输入目标机器 IP，自动网络握手并探测 NFS 端口（2049）；
   - **自动拉取共享列表**：调用 `showmount` 自动枚举目标机器已导出的所有共享路径供用户单选；
   - **人性化权限引导**：若探测受阻，统一精准引导用户 *“请检查目标机器的NFS访问权限”*。
3. **每个挂载点独立的实时吞吐看板**：
   - 直接从 Linux 内核 `/proc/self/mountstats` 读取硬件级 IO 计数器；
   - 实时计算各挂载点独立每秒读取速率（MB/s）、每秒写入速率（MB/s）与累计传输总量，哪个目录在搬砖一目了然。
4. **四重深度健康体检**：
   - 网络 Ping 延时测试（ms）；
   - NFS 端口连通性握手；
   - 目录安全读取延时（ms，带 2 秒超时防假死保护）；
   - 临时探针写入与落盘验证（ms，精确校验可写 / 只读权限状态）。
5. **极简零依赖（Zero-Dependency）**：
   - 完全基于飞牛系统自带的 Python3 标准库构建，无需安装繁重的 pip 第三方包；
   - 内存占用仅 **~25 MB**，待机 CPU **0.0%**。

## 🚀 快速一键安装与部署

### 方式一：飞牛宿主机一键安装（推荐）

直接在飞牛 SSH 终端执行（或拉取本项目代码后执行）：

```bash
cd /opt
sudo git clone https://github.com/Aragamiz/FNHyperMount.git fn-hypermount-src
cd fn-hypermount-src
sudo bash scripts/install.sh
```

脚本将自动：
1. 检查 Python3 与 `nfs-common` 环境；
2. 部署后台与前端到 `/opt/fn-hypermount`；
3. 注册并启用 `fn-hypermount.service` 与开机自愈服务；
4. 启动 Web 控制台，默认访问地址：`http://<飞牛IP>:8099`。

## 📖 向导式挂载操作指南

打开浏览器访问 `http://<飞牛IP>:8099`，点击右上角 **【添加 NFS 挂载】**：

1. **第一步（探测目标机器）**：
   - 输入目标机器 IP 地址（例如 `10.25.0.11` 或 `192.168.6.x`）；
   - 点击【探测目标机器】，系统自动测试延时并列出目标机器导出的共享目录；
   - *提示*：若探测失败，系统将提示 *“请检查目标机器的NFS访问权限”*。
2. **第二步（选择目录与本地路径）**：
   - 在下拉菜单中选择需要的共享目录；
   - 输入飞牛本地挂载路径（如 `/vol1/1000/NFS_Share`），本地目录不存在时系统会自动安全创建。
3. **第三步（选择运行策略）**：
   - 🌟 **工业级高可靠模式 (automount, 推荐)**：按需激活，开机不卡顿，目标机器重启自动重连；
   - ⚡ **常驻直接挂载模式**：适合全天候稳定在线的高并发直挂场景；
   - 🛡️ **安全只读模式 (ro)**：只读挂载，防止误删目标机器上的源文件。
4. **第四步（自动验收完成）**：
   - 系统自动写入 `/etc/fstab`（自动建立安全备份）；
   - 依次执行网络连通、端口握手、读延时测试与写探针验收，打绿勾完成！

## 🛡️ 安全与回滚机制

- **自动备份**：任何针对 `/etc/fstab` 的修改，系统都会在 `/etc/fn-hypermount/backups/fstab.<timestamp>` 建立备份（最多保留最新 10 份）。
- **独立标记块**：App 仅维护 `# --- BEGIN FN-HYPERMOUNT MANAGED ---` 与 `# --- END FN-HYPERMOUNT MANAGED ---` 之间的内容，绝不破坏飞牛原有的根分区、交换分区或其它系统挂载。
